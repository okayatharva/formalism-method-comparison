# Python-Based Formalism Analysis

## 10-Paper Extension

This folder contains a Python and Streamlit-based analysis
of the 10 additional scientific papers researched as part
of the Knowledge Discovery project.

The analysis is separate from the original six-paper research
and does not modify the existing research records.

---

## Purpose

The purpose of this analysis is to investigate whether
scientific methods can be meaningfully grouped by their
underlying formal operation rather than only by their
research topic.

The dashboard compares:

- Topics
- Objects
- Assumptions
- Guarantees
- Operations
- Formal proof / theorem support
